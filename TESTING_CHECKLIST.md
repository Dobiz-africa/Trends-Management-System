 TrendsDesk report acceptance checklist

- [ ] Official logo and orange/blue/white theme appear on login, portal, and generated documents.
- [ ] Notification panel remains above dashboard content and closes with Escape.
- [ ] In-app notifications generate one email per active target-role user without duplicates.
- [ ] Multi-word village, ward, plot, project number, and WO date survive PDF import and workflow refreshes.
- [ ] Merged field PDF is uploaded once and remains viewable by authorized roles.
- [ ] GIS Map and GIS Certificate have distinct View and Download actions and both block VO2 when absent.
- [ ] A separate Final GIS Map and Final GIS Certificate checkpoint appears after Works Instruction and blocks Finance when either final file is absent.
- [ ] VO1/VO2 rows can be deleted; an empty draft is allowed but cannot be finalized.
- [ ] Works Valuation and Works Instruction show full location and enlarged signature space without extra rules.
- [ ] Removed team-notification, work-completion, and duplicate-GIS stages do not appear.
- [ ] Annexure long customer names print without overlap; reference and date align right.
- [ ] Payment Certificate shows Work Completed to Date as 0, black deductions, correct words/override, and corrected signature blocks.
- [ ] Tax Invoice table ends at Amount Due, followed by banking details and payment terms.
- [ ] BPC Spreadsheet and List of Jobs print landscape with Work Order Date, Start Date, Completion Date, % Completion, and full responsible-person labels.
- [ ] Finance can save/reopen a draft, preview all five documents, validate, and finalize it exactly once.
- [ ] Annexure, Invoice, BPC Spreadsheet, and List of Jobs complete on finalization; Payment Certificate remains pending signature without blocking progress.
- [ ] Only admins can recycle/restore a work order; normal lists exclude recycled records and audit metadata is retained.
- [ ] Private scan URLs expire and unauthorized roles cannot query tables, transition workflows, or download files.
